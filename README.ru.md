# Shadowsocks Прокси-Сервер

[![en](https://img.shields.io/badge/lang-en-blue.svg)](README.md)
[![ru](https://img.shields.io/badge/lang-ru-red.svg)](README.ru.md)

Простой Shadowsocks AEAD прокси-сервер без ограничений для личного использования с друзьями и семьёй.

## Возможности

- **Протокол**: Shadowsocks AEAD (ChaCha20-Poly1305)
- **Простая Настройка**: Не требует базы данных, только переменные окружения
- **Без Ограничений**: Нет лимитов bandwidth, соединений или фильтрации доменов
- **Docker Ready**: Простое развертывание с Docker и docker-compose
- **Безопасность**: Генерация паролей на основе HMAC из мастер-секрета
- **Telegram Бот**: Опциональный бот для простого управления пользователями

## Быстрый Старт

### Требования

- Docker 20.10+
- Docker Compose 2.0+

### Шаг 1: Клонирование Репозитория

```bash
git clone https://github.com/OnyxBishop/shadowsocks-proxy.git
cd shadowsocks-proxy
```

### Шаг 2: Настройка Окружения

Создайте файл `.env`:

```bash
# Сгенерируйте безопасный мастер-секрет (минимум 32 символа)
SS_MASTER_SECRET=$(openssl rand -base64 48)
SS_USERNAME=ваше_имя_пользователя

echo "SS_MASTER_SECRET=${SS_MASTER_SECRET}" > .env
echo "SS_USERNAME=${SS_USERNAME}" >> .env
```

### Шаг 3: Запуск Сервера

```bash
# Сборка и запуск
docker-compose up -d

# Просмотр логов
docker-compose logs -f proxy
```

Вы должны увидеть:
```
Shadowsocks server initialized
SHADOWSOCKS proxy server started on 0.0.0.0:1080
```

### Шаг 4: Получение Данных для Подключения

Сервер сгенерирует детерминированный пароль на основе вашего имени пользователя и мастер-секрета:

```python
# Для ручного расчёта пароля:
import hmac
import hashlib

username = "ваше_имя_пользователя"
master_secret = "ваш_мастер_секрет_из_env"

ss_password = hmac.new(
    master_secret.encode('utf-8'),
    username.encode('utf-8'),
    hashlib.sha256
).hexdigest()[:32]

print(f"Ваш SS пароль: {ss_password}")
```

### Шаг 5: Настройка Клиента

**Данные для подключения:**
- **Сервер**: ip-вашего-сервера
- **Порт**: 1080
- **Пароль**: (сгенерирован из username + master secret)
- **Шифрование**: chacha20-ietf-poly1305

**Формат Shadowsocks URL:**
```
ss://chacha20-ietf-poly1305:ВАШ_ПАРОЛЬ@ip-вашего-сервера:1080
```

**Рекомендуемые клиенты:**
- **iOS**: Shadowrocket, Potatso Lite, V2Box
- **Android**: Shadowsocks Android, V2Box
- **Windows**: Shadowsocks-Windows, Hiddify
- **macOS**: ShadowsocksX-NG

## Конфигурация

### Переменные Окружения

| Переменная | Обязательная | По умолчанию | Описание |
|-----------|--------------|--------------|----------|
| `SS_MASTER_SECRET` | Да | - | Мастер-секрет для генерации паролей (мин 32 символа) |
| `SS_USERNAME` | Нет | `default_user` | Имя пользователя для генерации пароля |
| `PROXY_HOST` | Нет | `0.0.0.0` | Адрес привязки |
| `PROXY_PORT` | Нет | `1080` | Порт прослушивания |
| `PROXY_PROTOCOL` | Нет | `shadowsocks` | Протокол (должен быть shadowsocks) |

## Как Это Работает

1. **Генерация Пароля**: Сервер генерирует детерминированный пароль через HMAC-SHA256:
   ```python
   password = HMAC-SHA256(master_secret, username)[:32]
   ```

2. **Подключение Клиента**: При подключении клиента:
   - Отправляет 32-байтовую соль
   - Отправляет зашифрованный запрос
   - Сервер выводит ключ используя соль и пароль
   - Сервер расшифровывает и проксирует соединение

3. **Без Ограничений**: Весь трафик проксируется без:
   - Лимитов bandwidth
   - Лимитов соединений
   - Фильтрации доменов
   - Аутентификации пользователей через базу данных

## Безопасность

### Безопасность Паролей

- Используйте сильный мастер-секрет (минимум 32 символа)
- Генерируйте безопасно: `openssl rand -base64 48`
- Держите в секрете и не делитесь им
- Все ваши друзья/семья могут использовать один сервер с разными именами пользователей

### Сетевая Безопасность

1. **Используйте файрвол:**
   ```bash
   # Разрешите только порт прокси
   ufw allow 1080/tcp
   ufw enable
   ```

2. **Рассмотрите использование VPN или частной сети** для дополнительной безопасности

3. **Мониторьте ваш сервер** на необычную активность

## Развертывание

### Production Развертывание

```bash
# Запуск в фоновом режиме
docker-compose up -d

# Просмотр логов
docker-compose logs -f proxy

# Перезапуск сервера
docker-compose restart proxy

# Остановка сервера
docker-compose down
```

### Использование Ресурсов

- **Память**: ~50-100MB при нормальной нагрузке
- **CPU**: Минимальное (шифрование эффективное)
- **Сеть**: Зависит от вашего использования

## Устранение Неполадок

### Соединение отклонено

```bash
# Проверьте, прослушивается ли порт
netstat -tlnp | grep 1080

# Проверьте Docker
docker-compose ps

# Проверьте логи
docker-compose logs proxy
```

### Ошибка аутентификации

1. Проверьте, что SS_MASTER_SECRET установлен правильно
2. Убедитесь, что используете правильное имя пользователя
3. Пересчитайте пароль используя формулу выше
4. Проверьте логи сервера на ошибки расшифровки

### Медленные соединения

Этот сервер не имеет лимитов bandwidth, поэтому медленные соединения обычно из-за:
- Скорости сети вашего сервера
- Throttling от вашего ISP
- Перегрузки сети

## Несколько Пользователей

### Вариант 1: Использование Telegram Бота (Рекомендуется)

1. Настройте Telegram бота (см. `shadowsocks-proxy/bot/README.md`)
2. Пользователи отправляют `/start` боту
3. Бот автоматически генерирует учетные данные и SS ссылки
4. Пользователи сохраняются в `users.json`

### Вариант 2: Ручная Настройка

Чтобы добавить больше пользователей (друзей/семью), им нужно только:

1. IP вашего сервера и порт (1080)
2. Их собственное уникальное имя пользователя
3. Мастер-секрет (поделитесь безопасно)

Каждое имя пользователя сгенерирует разный пароль, но все используют один мастер-секрет.

**Пример:**
- Алиса: username="alice" → password=HMAC(secret, "alice")
- Боб: username="bob" → password=HMAC(secret, "bob")
